# Prosjektbibliotek

Felles lokalt referanserepo for ressurser som kan brukes på tvers av prosjekter. Opprettet 13. september 2026. Versjonert lokalt, uten GitHub-remote eller skysynkronisering.

## Katalog

- [Kystvann, CUDA WebShader og WebGPU](repoer/coastal-webgpu-2026-09-20.md): tre vann-/GPU-referanser, Unity-vurdering, lisenser og festede versjoner. [JSON-katalog](repoer/coastal-webgpu-2026-09-20.json).

- [Ti åpne verktøy fra Sentient](repoer/sentient-2026-09-12.md): lenker, formål, lisenser, mulige bruksområder og begrensninger.
- [Maskinlesbar katalog](repoer/sentient-2026-09-12.json): samme ti verktøy med søkeord og kilder for senere søk og automatisering.

Referansene beskriver kandidater, ikke installerte eller verifisert fungerende integrasjoner. Kontroller aktuell dokumentasjon og valgt versjon før bruk. Prosjektspesifikke beslutninger hører hjemme i det aktuelle prosjektet.
