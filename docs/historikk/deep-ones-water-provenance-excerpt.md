## Reference provenance

The implementation is authored here, informed by [Coastal Simulation](https://github.com/iamtechartist/coastal-simulation), [WaterCuda](https://github.com/SamG-Coder/WaterCuda), [Emil J's Godot tutorial](https://www.youtube.com/watch?v=B0T7UxjsLxU) and [Craig Reynolds' boids work](https://www.red3d.com/cwr/boids/). No reference source code was copied. The unlicensed Godot example was not imported. CUDA, FFT ocean simulation and a full shallow-water fluid solver are not runtime dependencies.

The generated far-rock image has its prompt, hash and attribution in [background-provenance.json](aquatic/background-provenance.json). The built-in image tool did not expose an exact model version. Concept fidelity is assessed from actual runtime images; a photorealistic concept does not certify AAA graphics in the delivered game.
