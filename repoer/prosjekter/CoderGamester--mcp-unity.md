# CoderGamester/mcp-unity

Separat Unity MCP-integrasjon, tidligere nevnt som kandidat.

[Åpne originalrepo](https://github.com/CoderGamester/mcp-unity) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Sammenlign funksjoner mot konkrete Unity-editoroppgaver og eksisterende automatisering.

**Merknader:** Ingen festet commit eller dokumentert lokal test i den bevarte kilden. Må ikke forveksles med CoplayDev/unity-mcp.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
