# Suwayomi/Suwayomi-Server

Manga-leserserver kompatibel med Mihon/Tachiyomi-utvidelser, med klienter og nettgrensesnitt.

[Åpne originalrepo](https://github.com/Suwayomi/Suwayomi-Server) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Referanse for bibliotek, leseframdrift og klient/server-design.

**Merknader:** README beskriver en selvstendig implementasjon, uttrykkelig ikke en fork. Innleggets historikk er upresis; påstanden om immunitet mot juridiske krav er ikke underbygget og brukes ikke som beslutningsgrunnlag.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
