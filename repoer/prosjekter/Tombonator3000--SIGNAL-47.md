# Tombonator3000/SIGNAL-47

Eget førstepersonsspill om kosmisk etterforskning ved SARO i New Mexico i 1986, bygget med Unity/URP og Blender.

[Åpne originalrepo](https://github.com/Tombonator3000/SIGNAL-47) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Referanse for fysiske interaksjoner, feltkamera og fotoframkalling, kontrollpunktlagring, dokumentert spillerreise, isolerte testprofiler og sporbar sammenheng mellom kilde, bygg og leveranse.

**Merknader:** README ved innhentet commit omtaler en Visual10-utgave og en nyere NightSky12-testkandidat med ventende spillerreise/ytelsesmåling. Dette er historikk fra repoet, ikke nye tester i katalogarbeidet. Bevar Unity 6000.3.22f1, URP 17.3.0, Input System 1.20.0 og Blender 4.5.13 LTS ved videre prosjektarbeid. Spillpakker følger ikke et rent klon. Ingen rotlisens er registrert; egne assets og tredjepartskreditering må håndteres separat.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
