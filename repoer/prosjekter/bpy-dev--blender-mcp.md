# bpy-dev/blender-mcp

Blender MCP-distribusjon med historisk lokal saved-file-verifikasjon.

[Åpne originalrepo](https://github.com/bpy-dev/blender-mcp) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Inspekter lagrede scener, finn runtime API-signaturer, lag separate checkpoints og verifiser render/FBX-rundtur.

**Merknader:** Vurdert e8ac4088d4a3e0469d3eff9f9bb2dd717e899219 med Blender 4.5.13; GPL-3.0-or-later oppgitt. Utvalgte upstream-tester: 83 bestått, 7 hoppet over, 1 feil. Missing-files-verktøy krevde fallback. Live UI og CUDA-verktøy var ikke verifisert.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
