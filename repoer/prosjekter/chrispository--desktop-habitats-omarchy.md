# chrispository/desktop-habitats-omarchy

Fork av Desktop Habitats som pakker akvariene som Omarchy-plugin med Linux-bakgrunn, skjermtilpasning og innstillingspanel.

[Åpne originalrepo](https://github.com/chrispository/desktop-habitats-omarchy) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Referanse for Three.js-scener som skrivebordsbakgrunn på Omarchy, individuelle skjermoppsett og Blender-rigget sjøanemone med bevegelige tentakler.

**Merknader:** Omarchy-spesifikk integrasjon med Qt6 WebEngine/layer-shell; er ikke dokumentasjon på generell Linux- eller Unity-kompatibilitet. README varsler betydelig GPU-bruk. MIT-kode og Three.js/Poly Haven-kilder er oppgitt, men Fab-materialer er også kreditert og må følge sine egne assetvilkår. Ikke installert eller kjørt ved katalogiseringen.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
