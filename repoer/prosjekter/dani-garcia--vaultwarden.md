# dani-garcia/vaultwarden

Alternativ Bitwarden-kompatibel server skrevet i Rust, for egen drift.

[Åpne originalrepo](https://github.com/dani-garcia/vaultwarden) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Kandidat til separat passordinfrastruktur.

**Merknader:** Uoffisiell implementasjon. README beskriver nesten komplett API-støtte; dette garanterer ikke alle betalte Bitwarden-funksjoner eller framtidig klientkompatibilitet. Støtte går via Vaultwarden. Ingen server er satt opp.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
