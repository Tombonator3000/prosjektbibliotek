# multimodal-art-projection/YuE

YuE2-system for musikkgenerering med redigerbar melodi-/akkordplan, vokal og akkompagnement, samt Python-API og agent-skill.

[Åpne originalrepo](https://github.com/multimodal-art-projection/YuE) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Kandidat for senere vurdering av lokal musikkproduksjon og kontrollert variasjon gjennom eksplisitte komposisjonsplaner; API-et deler planlegging, semantisk generering, syntese og dekoding i steg.

**Merknader:** Main dokumenterer YuE2; original YuE ligger på YuE-v1-grenen. README oppgir Linux, Python 3.12 og NVIDIA BF16-GPU med 24 GB VRAM. Apache-2.0 gjelder kode/skill/docs; modellvektene har separat CC BY-NC 4.0 med tilleggstillatelse for skapere, og README skiller privat/skaperbruk fra kommersiell selskapsbruk. Les MODEL_LICENSE før et konkret valg. Ingen modell er lastet ned, kjørt eller kvalitetsvurdert her.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
