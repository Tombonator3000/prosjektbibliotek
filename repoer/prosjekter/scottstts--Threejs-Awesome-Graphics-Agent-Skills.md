# scottstts/Threejs-Awesome-Graphics-Agent-Skills

Samling av Three.js-skills og implementasjonseksempler for materialer, lys, vann, vær, prosedyrisk geometri, VFX og visuell validering.

[Åpne originalrepo](https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills) · [Tilbake til katalog](../../KATALOG.md)

## Bruk og avgrensning

**Mulig gjenbruk:** Slå opp avgrensede grafikksystemer og tilhørende eksempler, særlig hav/undervann, materialer, atmosfære, skygger og diagnostiske visninger. Bruk prinsippene om reproduserbare innganger og tidsmessig stabilitet ved egne vurderinger.

**Merknader:** Three.js/TSL/WebGPU/GLSL-referanser, ikke Unity-pakker eller en komplett spillmotor. Eksempelgalleriet eier noe sceneoppsett som ikke følger med den enkelte skillen. Repoets kvalitets- og valideringspåstander er ikke etterprøvd her; ingen skills er installert og ingen demo er kjørt. MIT-lisensfil er innhentet.

Kildene er hentet og katalogisert. Ingen ny installasjon, spilltest eller ytelsesmåling er utført i denne katalogiseringen. Historiske tester gjelder bare dokumentert versjon og miljø.
